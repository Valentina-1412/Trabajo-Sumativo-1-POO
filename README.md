El proyecto Llanquihue Tour, tiene por finalidad digitalizar las operaciones de una empresa de turismo con el mismo 
nombre. Entre las nuevas funciones, se priorizó el ordenar a las personas que trabajan en y con la empresa (guías, 
anfitriones, el transporte y el alojamiento), así como también quienes adquieren sus servicios (los clientes).
En el proyecto tenemos dos paquetes, que son APP y Model. El primero contiene la clase Main, quien es la encargada de 
ejecutar el programa como tal. Mientras que Model va a contener a todas las otras clases: persona (clase base), cliente, 
anfitrion del alojamiento, alojamiento, guías, transporte y la base de datos. 
Para ejecutar Main, basta con crear el objeto, correspondiente a una clase de las que mencionamos, lo guardamos en la
base de datos y ejecutamos.
